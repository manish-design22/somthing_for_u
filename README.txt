LOVE WEBSITE — CUSTOM 5 PAGE VERSION

1) Open this folder in VS Code.
2) Put your JPG pictures inside assets/.
3) Use these exact filenames:
   assets/cat1.jpg  -> Page 1 picture
   assets/cat2.jpg  -> Page 2 picture
   assets/cat3.jpg  -> Page 3 picture
   assets/cat4.jpg  -> Page 4 picture
4) Optional:
   assets/music.mp3 -> background music

PAGE ORDER:
1. I have something special to tell you...
2. Be honest with me... / Do you trust me?
3. One more thing... / Do you also love me?
4. Last question, I promise! / Will you be mine forever?
5. You made me the happiest!

The design uses a different background palette from the screenshots:
deep navy + teal/mint + soft blue + warm gold/coral accents.

The JPG slots are already placed where the cat/character appears in your reference screenshots.
Just replace the placeholder JPG files with your own images, keeping the same filenames.

To run:
- VS Code -> install Live Server (optional)
- Right click index.html -> Open with Live Server
